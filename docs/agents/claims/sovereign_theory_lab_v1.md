# Sovereign Theory Lab v1

## Classification

Prospective experiment and adjudication instrument. This change creates no live
model dispatch, performance result, supported theory, falsified theory, routing
change, or capture closure.

## Authority

The operator authorizes construction of testable theories for the sovereign
desktop plane. External task acceptance remains authoritative. Runtime identity
must be attested. Transport errors remain non-decisive. The capture ledger remains
the only authority for capability amortization.

## What lands

- a strict theory, task, metric, arm, predicate, observation, plan, and report contract;
- deterministic counterbalanced arm scheduling;
- runtime-fallback and incomplete-telemetry exclusion;
- support and falsification rules frozen before observations;
- 22 desktop hypotheses covering context, cache, scheduling, 4060/3090 roles,
  speculative decoding, KV tiers, retrieval, composition, and distillation;
- ten zero-model-call tests;
- permanent CI;
- `tiertheory` CLI.

## Failure default

Until a theory has enough distinct tasks and decisive replicates in every compared
arm, its result is `PARTIAL` or `UNMEASURED`. An attractive mechanism, vendor
benchmark, or one successful run cannot become a routing rule.
