# Estate Kernel v1

## Classification

Headless execution and control-plane substrate. This change creates no model call,
provider credential use, publication, destructive repository action, or production
routing verdict.

## Authority

- external acceptance remains authoritative for admission to the accepted-action cache;
- workflow history records side-effect intent and result but does not grant the effect;
- Work IR plans are proposals until existing Tier Bench execution and acceptance surfaces
  execute them;
- verifier plans create adversarial cases but do not rewrite the source acceptance contract;
- attention plans request operator authority but cannot exercise it;
- Git and the local evidence directories remain the durable record.

## What lands

- immutable SHA-256 content-addressed storage;
- exact accepted-action cache identities;
- conflicting-result and corruption refusal;
- append-only hash-chained workflow histories;
- idempotency and compensation planning;
- supervisor restart-scope calculation;
- typed Work IR and deterministic-first lowering;
- common-subwork elimination with symbolic downstream cache refusal;
- mutation, metamorphic, fuzz, and differential verifier plans;
- review batching, evidence-return, reattachment packets, and attention SLOs;
- `tierestate` CLI, examples, documentation, zero-model-call tests, and CI.

## Qualification boundary

The assembled branch is qualified by zero-model-call tests and headless fixture smoke only.
It does not yet establish production cache yield, restart recovery across a real machine
failure, verifier effectiveness on live repository defects, or measured operator-attention
savings. Those claims require runtime receipts from distinct real work.

## Failure default

A missing digest, unsupported schema, changed runtime, incomplete acceptance receipt,
side-effectful cache candidate, altered idempotency intent, weak verifier plan, or incomplete
review request fails closed. No positive operational claim is inferred from the existence of
this code.

## First physical pass

Instrument at least one hundred historical `tier run`, context materialization, model call,
grader, and render actions. Measure exact accepted-action reuse, avoided model and tool
calls, storage cost, invalidation causes, verifier fault-detection yield, workflow recovery,
and operator minutes recovered before promoting the Estate Kernel into production routing.
