# World Experience Atlas v1

## Classification

Planning and gap-analysis instrument. This change makes no claim that an imported
pattern is implemented, beneficial, or appropriate for production.

## Authority

The atlas may rank and sequence candidate mechanisms. It cannot promote a pattern,
change a production route, grant execution authority, or close a capture ledger
entry. Those transitions remain with the relevant runtime, acceptance, theory, and
capture instruments.

## What lands

- eleven adjacent engineering disciplines;
- fourteen primary reference surfaces;
- forty-four imported patterns;
- explicit current gaps, desktop translations, hypotheses, first experiments,
  dependencies, scoring, and failure defaults;
- deterministic dependency-closed planning;
- a `tieratlas` CLI;
- zero-model-call tests and CI.

## Failure default

An untested pattern remains a planning candidate. A failed experiment preserves the
result and blocks production adoption; it does not invite narrative reinterpretation.
