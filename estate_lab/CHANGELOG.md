# Changelog

## 0.3.0

- Added the public AXM Interaction Floor specification with portable adapter, request, event, response, conformance, registry, and gap-ledger objects.
- Added eight conformance profiles, five computed quality tiers, seventeen dynamic vectors, static profile checks, explicit negative controls, and content-derived submissions.
- Added a zero-dependency command-json reference adapter and an `init-adapter` generator whose output uses the same public vectors without importing the AXM estate runtime.
- Added detached submission and registry verification, deterministic Markdown and AsyncAPI projections, a WIT Component Model interface, and binding guidance for CloudEvents, MQTT, WebSocket, OSC, and W3C WoT.
- Added a forty-item executable gap ledger covering protocol, identity, authority, versioning, distribution, independent verification, SDKs, fuzzing, security, physical proof, accessibility, community submissions, and resurrection.
- Expanded the commodity catalog from 55 to 81 candidates and from 11 broad families to 27 capability categories, including interoperability standards, supply-chain primitives, agent protocols, conformance models, accessibility references, and public catalog patterns.
- Expanded the permanent test estate to 48 tests plus dedicated floor conformance and reference-scenario gates.

## 0.2.0

- Added a content-addressed 55-candidate OSS, community, standards, and commodity catalog across 11 capability families.
- Added consume, adapt, reference, and reject decisions with explicit license posture, adapter, substitution, authority-exclusion, risk, and evidence requirements.
- Added deterministic acquisition-plan projection and CLI filtering by decision, category, priority, and estate target.
- Added catalog schema, 11 catalog tests, documentation, exact package validation, and CI coverage.

## 0.1.0

- Added the AXM estate manifest with 14 organs, 15 adapters, and 18 routes.
- Added explicit route admission, weighted scoring, tiered fallback, and complete evaluation receipts.
- Added semantic authority checks for actor, role, mandate, and ownership epoch.
- Added deterministic state reduction, desired-output projection, causal debrief, event idempotence, and content-derived identifiers.
- Added synthetic, artifact, human-refusal, and bounded command adapter modes.
- Added repository discovery, smoke and full probe profiles, adapter-health projection, and retained probe logs.
- Added five cross-estate reference scenarios, 16 routing trials, and 15 injected fault trials.
- Added checksummed JSON, JSONL, Markdown, and standalone HTML run receipts.
- Added Windows and portable launchers, JSON Schemas, 19 tests, and a two-version GitHub Actions qualification workflow.
