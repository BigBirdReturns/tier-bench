# Action Player Floor community and commodity map

Inclusion is discovery, not qualification. Every donor remains outside Arc authority
and behind an AXM-owned capability cell.

| Community or product | Pattern consumed | Floor seam | Refusal boundary |
|---|---|---|---|
| Unreal Gameplay Ability System | authoritative Gameplay Effects separated from cosmetic Gameplay Cues | Arc semantic cues and World presentation mappings | World cues may not carry gameplay code |
| GGPO | save, load, and advance deterministic frames without rendering | exact trace replay and receiver comparison | netcode or rollback library may not define action law |
| Godot rollback netcode | tick-owned state, log inspection, mismatch navigation, replay | Action Trace and Cue Studio | inspector may not modify source traces |
| Castagne | text-backed move definitions, reusable modules, combo tests, frame inspection | Arc authoring and conformance references | Castagne runtime does not become Arc authority |
| Ikemen GO | long-lived content compatibility, scripting, training, rollback | profile migration and compatibility corpus | legacy compatibility does not waive current player gates |
| Unity Input System | action maps, control schemes, rebinding, sensitivity, haptics | player input and accessibility provider cells | device provider may not widen action windows |
| Cinemachine | follow, orbit, collision, recenter, framing, impulse | camera provider cells | camera may not select targets or move authoritative actors |
| Unity Animation Rigging | runtime hand, tool, look, and mechanism alignment | animation contact provider cell | constraints may not determine hits or mechanism completion |
| Unity CharacterController samples / OpenKCC | grounding and locomotion reference | visual locomotion provider cell | controller may not acquire Arc position authority |
| Watch Dogs / Motion Matching GDC practice | shared animation architecture and declarative markup | presentation profile and cue mapping | animation metadata may not replace Arc state |
| Skullgirls / DOOM / Uncharted GDC practice | anticipation, strong contact, responsive full-body action | readability and contact gates | visual simulation may not outrank responsiveness or law |
| Xbox Accessibility Guidelines | remapping, sensitivity, timing and input alternatives, redundant cues | accessibility profiles and human evidence | accessibility changes to timing must be authored in Arc profiles |

## Provider tournament rule

A tournament uses one exact intent, action spec, trace corpus, presentation profile,
asset set, device profile, and platform budget. It publishes context-bound evidence,
not a universal winner.

Required measurements include:

- device event to admitted Arc tick;
- admitted tick to visible and audible response;
- dropped or duplicated buffered inputs;
- camera occlusion and correction distance;
- cue-to-animation, cue-to-audio, and cue-to-haptic latency;
- frame-time distribution and allocations;
- mechanism and telegraph screen footprint;
- remapping and profile round-trip;
- exact trace and receipt equality after substitution;
- provider removal and fallback reconstruction.

The control question is whether a provider can enter and leave while mechanic meaning,
cue coverage, player accessibility, exact trace, and accepted result remain unchanged.
