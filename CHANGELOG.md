# Changelog

## 0.1.0 — Feb 13, 2026

Initial public release.

- 12 deterministic tasks across T0–T3
- Config-driven model registry (`models.json`)
- 7 provider implementations (Anthropic, OpenAI, Mistral, DeepSeek, Google, Ollama, OpenAI-compatible)
- Cost guard with per-call and daily budget limits
- Orchestrator with planner/worker decomposition
- Task contribution system with validator
- HTML cheatsheet generator
- GitHub Pages deployment via Actions
