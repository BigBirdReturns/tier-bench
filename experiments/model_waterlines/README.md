# Model waterlines

This directory contains frozen substitution protocols and the catalog of every
known place where the same experiment can recover operator attention or capture
frontier residue.

A waterline is not a leaderboard. It is the cheapest route that preserves an
accepted outcome, operator burden, and escaped-defect record for a bounded task
family under the same tools, context, and referee.

Start with:

```text
opus5_fable5/protocol.json
opus5_fable5/tasks.json
catalog.json
```

The generic compiler and analyzer live in `tier_runner/model_waterline.py`.
Operational instructions are in `docs/model-waterline-observatory.md`.
