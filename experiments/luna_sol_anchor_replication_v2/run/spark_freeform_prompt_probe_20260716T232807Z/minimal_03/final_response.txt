Use this command in your writable environment to make the exact requested change:

```powershell
[System.IO.File]::WriteAllText('value.txt', "1`n", [System.Text.UTF8Encoding]::new($false))
```

It will set `value.txt` to exactly one `1` followed by one LF newline.
