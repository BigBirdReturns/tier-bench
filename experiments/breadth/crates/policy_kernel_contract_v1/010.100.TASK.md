# 010.100 Task — policy_kernel_contract_v1

**Status: CONTRACT FROZEN — implementation card NOT authorized.**
This card freezes the semantics of the policy kernel. Building the kernel is a
separate card, admissible only after `gastown_tier_run_smoke_v1` seals with a
verified receipt (see that crate's 010.100).

## What the policy kernel IS

A **pure decision function**. Inputs: a sealed task envelope, a cartridge
manifest, a tank (quota) snapshot, and an evidence index. Output: exactly one
hash-bound routing decision object, or exactly one `NO_DECISION` object.

The kernel does NOT: invoke a model, inspect credentials, modify scheduler
state, execute acceptance, spawn an adapter or model process, or read anything
outside its four declared inputs.

## Decision object — frozen minimum fields

```text
schema                      "tier-bench/policy-decision@1"
decision_id
task_envelope_sha256
cartridge_manifest_sha256
tank_snapshot_sha256
evidence_refs               list; may be empty only with capability_basis=unmeasured
selected_cartridge
capability_basis            one of: measured | hypothesis | unmeasured
quota_basis                 one of: observed | derived | declared | unknown
route_reason
fallback_order
operator_gate               bool — true means execution requires an operator act
observed_at                 the ONLY timestamp; detachable for determinism tests
snapshot_max_age
```

`NO_DECISION` is a first-class terminal object (same schema family, field
`no_decision_reason` from the closed enum below), never a bare nonzero exit.
Refusals are receipts too.

## Frozen invariants

1. **Determinism.** Identical input bytes → byte-identical decision minus
   `observed_at`.
2. **Fail closed.** Missing or unparseable input → `NO_DECISION`, never a
   guessed decision.
3. **Evidence honesty.** `capability_basis=measured` requires ≥1 entry in
   `evidence_refs` resolving to a committed result row. A `tier_ceiling` from
   models.json is `hypothesis`, always. A hypothesis serialized as measured is
   a contract violation, not a warning. (Today's registry yields almost
   entirely `hypothesis` decisions; that is the normal, honest state.)
4. **Staleness labeling.** A tank snapshot older than `snapshot_max_age` may
   support a decision only with `quota_basis` degraded to `derived` or
   `unknown` and `route_reason` naming the staleness. Stale may never present
   as current headroom.
5. **No credentials.** No field may carry a key, token, cookie, or a path to
   one. The future referee greps the serialized object; any hit fails.
6. **No execution.** The kernel process makes no network calls and spawns no
   subprocesses.

## Failure classes (closed enum for `no_decision_reason`)

`MISSING_INPUT` | `UNPARSEABLE_INPUT` | `NO_CAPABLE_CARTRIDGE` |
`QUOTA_EXHAUSTED` | `SNAPSHOT_TOO_STALE` | `ENVELOPE_UNSEALED` |
`EVIDENCE_UNRESOLVABLE`

## Boundary

tier-bench owns this decision semantics. Hosts (Gas Town, Agent Deck, a
terminal, cron) obtain decisions and execute them; they may not alter fields.
The control question for every field: could a different orchestrator consume
this tomorrow without changing evidence semantics? Anything host-specific
belongs in the work receipt's `external_refs`, never here.
