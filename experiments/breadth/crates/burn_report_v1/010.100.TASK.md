# 010.100 Task — burn report script

Create `scripts/burn_report.py` (stdlib only, Python 3.10+).

It reads per-session cost sidecars written by the cost sentinel and prints a
calibration report.

## Input

- `--state-dir PATH` (default: `experiments/breadth/run/.sentinel_state`)
- Each `*.json` file in that directory is one session:
  `{"offset": int, "cost_usd": float, "tier": str|null, ...}`
- Ignore files that are not valid JSON objects and any `*.ack` files.
- The session id is the filename without `.json`.

## Output (exact format, to stdout)

One line per session, sorted by `cost_usd` DESCENDING, ties broken by session
id ascending:

    <first 8 chars of session id>  $<cost_usd, 2 decimals>  <tier or ->

(two spaces between fields; `-` when tier is null/missing)

Then a blank line, then exactly these four summary lines:

    sessions: <N>
    total: $<sum, 2 decimals>
    median: $<p50, 2 decimals>
    p90: $<p90, 2 decimals>

Percentile rule (nearest-rank): p-th percentile = element at index
`ceil(p/100 * N) - 1` of the costs sorted ASCENDING.

If the directory is missing or has no valid sessions, print exactly
`no sessions` and exit 0. Always exit 0 on success paths.
