# 010.100 Task — crate scaffolder

Create `scripts/crate_new.py` (Python 3.10+, stdlib only).

CLI: `python scripts/crate_new.py --name NAME --dir DIR`

Creates directory `DIR/NAME/` containing exactly three files:

- `000.000.INDEX.md` — first line `# 000.000 Crate index — NAME`, then a
  read-order pointing at the other two cards, an "edit ONLY" placeholder
  line containing `<ALLOWED_FILE>`, a run-only referee placeholder line
  containing `<REFEREE_CMD>`, prohibitions on tests//crate//git, and the
  DONE-reply instruction.
- `010.100.TASK.md` — first line `# 010.100 Task — NAME`, then a `<SPEC>`
  placeholder.
- `020.100.ACCEPTANCE.md` — first line `# 020.100 Acceptance`, then a line
  containing `<REFEREE_CMD>` and the frozen-referee warning.

Rules: refuse to overwrite — if `DIR/NAME` already exists, print
`exists: <path>` and exit 1. On success print `created: <path>` and exit 0.
