# 010.100 Task — burn_report_json_v1

Add a `--json` flag to `scripts/burn_report.py`. Text output (no flag) must stay
byte-identical to today's behavior.

With `--json`, print EXACTLY one JSON object (one `json.dumps` call, nothing
else on stdout) carrying the same data as the text output, then exit 0:

- `"sessions"`: list, same order as the text rows (cost_usd DESC, then sid ASC),
  each item `{"sid": <full file stem, not truncated>, "cost_usd": <float>,
  "tier": <string or null>}` (tier is null when the sidecar has no tier).
- `"count"`: number of sessions (the text `sessions:` value).
- `"total"`, `"median"`, `"p90"`: same floats as the text summary
  (median/p90 are nearest-rank, unchanged from current code).

No valid sessions (empty/missing dir, all files malformed): with `--json` print
`{"sessions": [], "count": 0, "total": 0.0, "median": 0.0, "p90": 0.0}` and
exit 0 (text mode keeps printing `no sessions`).

Malformed / non-dict sidecar files stay silently skipped in both modes.
