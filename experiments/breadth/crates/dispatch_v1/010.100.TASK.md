# 010.100 Task — hand dispatcher

Create `scripts/dispatch.py` (Python 3.10+, stdlib only): run one "hand"
command against an arm directory, referee the result, append a receipt row.

CLI (all required):

    python scripts/dispatch.py --arm-dir D --hand-cmd CMD --referee RCMD --receipt PATH

Behavior:
1. Run CMD via the shell with cwd=D. Capture combined stdout+stderr to a log
   file `<PATH stem>_<n>.log` next to PATH (n = 1-based count of rows already
   in PATH, so logs never overwrite). A failing or crashing hand is not an
   error — proceed to the referee.
2. Run RCMD via the shell with cwd=D, capture output.
3. Append one JSON line to PATH (create file/dirs if needed):
   {"arm_dir": str, "hand_cmd": str, "pass": bool, "referee_exit": int,
    "referee_last_line": str, "log": str}
   where pass = (referee exit == 0), referee_last_line = last non-empty
   stdout line of RCMD (empty string if none), log = path to the log file.
4. Exit 0 if pass else 2. Never raise on hand/referee failure; internal
   errors may exit nonzero but must not corrupt existing receipt rows.
