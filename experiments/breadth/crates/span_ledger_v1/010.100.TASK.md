# 010.100 Task — span ledger

Create `scripts/span_ledger.py` (Python 3.10+, stdlib only).

It reads a JSONL file of half-open integer spans and reports merged coverage.

## Input

- CLI: `--input PATH` (required).
- Each line of the file should be a JSON object `{"start": int, "end": int}`
  describing the half-open interval `[start, end)`.
- Ignore, without error: lines that are not valid JSON objects, objects whose
  `start` or `end` is not an integer (booleans are not integers), and spans
  with `end <= start`.
- Input lines may be in any order and may contain duplicates.

## Semantics

Merge spans that overlap OR touch (a span ending at x merges with one
starting at x). After merging, report the number of merged spans and the
total number of integers covered.

## Output (exact, to stdout, then exit 0)

    merged: <count>
    covered: <total>

If the file is missing or contains no valid spans, print exactly `no spans`
and exit 0.
