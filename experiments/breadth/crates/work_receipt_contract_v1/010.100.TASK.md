# 010.100 Task — work_receipt_contract_v1

**Status: CONTRACT FROZEN — implementation card NOT authorized.**
This card converts the human-readable `700.100` receipt convention into a
portable machine contract. It extends — never replaces —
`schemas/tier_run_receipt.schema.json`; extended fields are additive.

## What a work receipt binds

The decision that authorized an attempt, the exact task and repository state,
the cartridge execution evidence, the candidate patch, the frozen referee,
and the resulting state transition. One receipt per attempt terminal.

## Frozen minimum fields

```text
schema                      "tier-bench/work-receipt@1"

predecessor_receipts        list of {path, sha256}; receipts form a DAG
```

## Frozen invariants

1. **`external_refs` never acquire authority.** A Bead ID, Gas Town rig,
   worker identity, or Agent Deck session may appear there; none may override
   the referee verdict, specification, acceptance predicate, evidence class,
   or terminal state. An external system claiming override is a validation
   failure.
2. **`unlocks`/`blocks` are logical, not operational.** The receipt kernel
   never calls Beads or Gas Town. A host adapter reads the *verified* receipt
   and projects effects into its scheduler. Beads is a rebuildable projection;
   committed envelopes and receipts are the authority. Replace the scheduler
   tomorrow without rewriting historical evidence.
3. **Local validation.** A receipt validates against only the predecessor
   receipts it names by path+hash. Validation requires no global history or
   central store; an unreachable predecessor degrades to a labeled
   `UNVERIFIED_PREDECESSOR` outcome, never a silent pass.
4. **One terminal per attempt.** Duplicate terminal receipts for one
   `attempt_id` are a validation failure.
