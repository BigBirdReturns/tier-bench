# 020.100 Acceptance

Driver-authored, frozen. If it seems wrong, it is not: match
[010.100](010.100.TASK.md) exactly.

The lane is operational when its first FORMAL exchange lands: a committed
receipt file matching the schema in 010.100, whose packet_sha256 and
response_sha256 reproduce from the committed packet/response bytes, whose
disposition was adjudicated by a driver in a named session/commit, and whose
ledger row records cost basis subscription-subsidized with surface and
effort named. A future validator (post-smoke implementation card) checks
these mechanically; until then the driver checks them by hand at commit time.
