## Standing hypothesis under test

"Gas Town's non-interactive preset/formula seam can host `tier run`" is a
HYPOTHESIS until this smoke. `tier run` is a one-shot patch runner, not a
conversational agent; the smoke targets Gas Town's documented public boundary
only (`gt` CLI, environment variables, `settings/agents.json`). If the
installed Gas Town cannot supply the fixed arguments plus the dynamic task
field without substantive wrapper logic, that is a useful transport failure —
NOT permission to build a custom worker framework.

## Task selection

A TRUE T1: one tightly scoped file, deterministic acceptance
(`fixtures/t1_impl_from_docstring/` is the default candidate). Multi-file is
T2 and out of scope; a later multi-file smoke is recorded honestly as T2.
The smoke measures TRANSPORT, not agent capability.

## Phase 1 — provider-free transport check (runs first, $0)

A local argument-capture fixture receives the Gas Town-generated invocation
and proves task text, repository path, file scope, and acceptance command
reach the intended `tier run` flags without shell reinterpretation or dropped
fields. Reuse the smoke-before-cage idiom (`tests/test_smoke_before_cage.py`).
Also provider-free: one intentional-failure run — acceptance deliberately
fails, must produce `REJECTED`/`ERROR` with preserved diagnostics, Bead left
open or explicitly blocked. A system that closes work because a process
exited, an agent claimed success, or a patch merely exists has failed the
evidence contract.

## Phase 2 — the one live dispatch

One subscription-backed T1 invocation through `tier run`, against a
disposable clone or pinned test repo. Preserve patch + all receipts, run
`tier verify`, leave the operator checkout unchanged.

## PASS requires all nine facts evidenced in one closure packet

1. Beads computed the item ready and recorded an atomic claim.
2. Gas Town launched the configured non-interactive surface with zero
   upstream code changes.
3. The official model CLI retained custody of authentication.
4. `tier run` emitted a candidate patch and complete backend telemetry.
5. The frozen referee returned `ACCEPTED`.
6. `tier verify` reopened every relevant hash and binding.
7. The accepted RECEIPT — not process exit, not model narration — authorized
   the Bead closure.
8. The Bead retains the receipt path and digest as closure evidence.
9. No patch was automatically applied or merged.
