# 010.100 Task — dispatch_fix_v1

Fix a Windows decode defect in `scripts/dispatch.py`.

Defect: both `subprocess.run(...)` calls (the hand launch and the referee
launch) pass `text=True` with no `encoding=`. On Windows the captured output
is decoded with the locale codec (cp1252); hand/referee output containing
UTF-8 bytes outside cp1252 (e.g. a right double quote U+201D) raises
`UnicodeDecodeError` inside `subprocess.run`, the except-branch replaces the
whole captured log with the error string, and the receipt row loses the
referee line.

Fix: on BOTH `subprocess.run` calls, capture with `encoding="utf-8",
errors="replace"` (keep `text=True` semantics otherwise unchanged — same
args, same timeout, same shell/cwd). Change nothing else in the file.

Verify: from the repo root run `python tests/test_dispatch_fix.py` (must end
`PASS dispatch_fix`) and `python tests/test_dispatch.py` (must end
`PASS dispatch` — must stay green).
