# 010.100 Task — burn_two_vendors_v1

Extend `scripts/burn_report.py` (repo root = your cwd) so ONE ledger reports BOTH
vendors' spend: the existing Anthropic sidecars AND the local Codex/OpenAI CLI
session logs. "Two tanks, one car."

## What to build

1. Discover where the Codex CLI writes per-session logs on this machine
   (start at `C:\Users\BAM-Desktop\.codex\` — look for `sessions/`, `log/`,
   `history/`, JSONL files with token/usage rows). Parse cost per session; if
   logs carry tokens but not dollars, price them with a small built-in table
   (gpt-5.6-sol / gpt-5.3-codex-spark rates from `cost_guard.py` if present
   there, else hardcode with a comment naming the source).
2. Add a `vendor` dimension: every session row gains `anthropic` or `openai`.
   `--json` output gains a top-level `"vendors"` object:
   `{"anthropic": {"total_usd": float, "sessions": int}, "openai": {"total_usd": float, "sessions": int}}`.
   Keep ALL existing flags (`--top`, `--min`, `--json`) working unchanged.
3. Add `--selftest`: builds a synthetic Codex-format session file in a tempdir,
   parses it through the same code path as real logs, asserts nonzero cost,
   prints `SELFTEST OK`, exits 0.
4. If no Codex logs exist on disk, the report must still run (openai sessions=0),
   never crash.

## Bounds

- Modify ONLY `scripts/burn_report.py`. No new files outside the tempdir at runtime.
- Diff ≤ 250 lines. Do not touch the sentinel hooks, dispatch.py, or any crate.
- When done, reply DONE + one line naming the Codex log path you found.
