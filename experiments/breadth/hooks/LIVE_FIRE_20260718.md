## Run 2a — injection, `TIER_SENTINEL_NOTICE_USD=0.01` (FAILED → finding 1)

Session `ccb7a62c-d09b-4817-9e81-abd3d1865030`. Child reported `NONE`; sidecar
showed `"tier": "NOTICE"` with **no** `last_warned_usd` — the sentinel crossed
the threshold, recorded the tier, and never warned.

**Finding 1 (bug, fixed):** PreToolUse fires between the first response and the
first PostToolUse. Its branch recorded `state["tier"]` without emitting, so
PostToolUse computed `crossed=False` and NOTICE (re-warn step 0) stayed silent
forever. Offline tests missed it because each fired one event on fresh state,
never the real Pre→Post interleaving. Fix: only warn-emitting branches record
the tier. Pinned by `test_pretooluse_does_not_swallow_crossing_warning`.

**Finding 2 (accuracy, fixed):** transcripts carry dated ids
(`claude-haiku-4-5-20251001`); registry keys are undated. Exact-match miss →
pessimistic fable fallback, ~10x overestimate for known families. Fix:
longest-prefix registry match before fallback. Pinned by
`test_dated_model_id_prefix_matches_registry`.
