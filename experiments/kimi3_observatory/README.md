# Kimi K3 Open-Weight Observatory fixtures

Copy `observatory.example.json` and `community.example.json` to local, uncommitted
files, then replace the D-drive roots and the exact Hugging Face repository identity.
The canonical downloaded model directory is read-only input. All scans, claims,
probes, and receipts go to the separately declared state directory.

The `.grid-active` marker is optional but recommended while the full baseline grid is
running. When it exists, a requested nightly or full observation cycle is downgraded
to the lightweight frequent profile. Community synchronization and static header
inspection continue, but large-shard hashing and numeric sampling wait.

Reddit access is fail-closed. Leave `approval_confirmed` false until Reddit has
explicitly approved the API use case and the three credential environment variables
are populated. GitHub discovery and manual JSONL import continue independently.
Community text is retained only as tainted hypothesis input with `training_use` fixed
to `prohibited`.
