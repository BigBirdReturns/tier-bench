1 · Key & models

Your Anthropic key stays in this browser and is sent only to api.anthropic.com. Administering to an Anthropic model runs each probe as a fresh, cold call (no shared memory). Testing a non-Anthropic model? Use Paste mode below — run the probes wherever you have that model, paste the ten answers, and grade them here.

Grader ≠ subject, honestly. An in-browser grader is still an Anthropic model, so it shares lineage with Anthropic subjects — the result carries a lineage-flagged caveat, exactly like our committed baseline. An independent, non-Anthropic grade is what clears it (see the offline merge_external_grades.py). These are your grades, single-administration — a signal, not a certificate.
