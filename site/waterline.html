The waterline: where the frontier actually is

We gave the same coding tasks to cheap and frontier models and graded them with tests the models never saw. Everything spec-shaped settled at the cheapest model. Across five hidden-graded tasks and three model families, the measured frontier came down to one named rule — and the second-cheapest model already handles it.

One picture

Each cell is a task, placed by the cheapest model that reliably clears it (3 of 3 trials against a hidden grader). Below the line is settled work — commodity, route it to the cheapest thing. Above the line is derived work — the residue that still separates models.

Fig. 1 — The measured waterline, July 2026. Five tasks, hidden graders, K=3. Tasks we designed to be senior/staff-difficulty — security-style parsing, plan review — sank below the line the moment grading was made honest (solvers can’t iterate against tests they can’t see).

The one task that separated models

The wildcard-matcher task asks a model to implement pattern matching from a complete written spec. One judgment inside it isn’t spelled out and must be committed to: what does a backslash mean inside [...]?

The rule that is the frontier (today, on this set): inside a character class, a backslash is a literal character — not an escape. Pattern [\] is a valid class that matches \, not a malformed pattern. Two of five haiku attempts judged it malformed and raised an error. That single commitment, cascading through the hidden tests, was the entire measured difference between models.

What this means

1 — “Difficulty tiers” stopped separating models. Our own T0–T4 ladder (format → implement → debug → refactor → plan) was built on the industry’s mental model: harder work needs bigger models. Measured honestly, the cheapest 2026 model clears all of it. The axis that separates models is not how hard the work is but whether the answer is written down — spec-following vs. judgment calls a spec constrains but doesn’t state.

2 — The frontier is a list, and today the list has one item. Not “GPT vs Claude,” not open-vs-closed: on everything we can grade without showing models the answer key, the residue that justifies paying more is one backslash-semantics rule, named, priced at 19¢ of extra spend per attempt, and already handled one rung up. The job now is growing that list honestly — with tasks where the answer must be derived, not followed.

3 — Measurement is the control plane. As open and proprietary models converge, “which logo” matters less than: what ran, what passed, what was verified, what was a transport failure, and what can be routed cheaper next time. Ask the repo directly:

Methods, honestly

Hidden grading — why every number here is trusted

Modern models are agentic: shown a test file, they iterate until green — which measures the pipe, not the model. Every result on this page is graded by tests the solver never saw, injected only after its answer was frozen. Our own first run made this mistake (“the floor cleared everything!” — it was reading the answer key); the fix is in the harness now.

Receipts vs. derived — and the transport failure that proved the point

A result is a receipt only if the raw model output was captured and locally graded. Three GPT-5.5 attempts arrived through a JSON pipeline that silently halved backslashes, making the code unloadable. Those rows are recorded as transport errors, never model failures — and mechanically-inverted repairs (which all pass) are labeled derived, never receipts. Separating model failure from transport failure is most of what makes cross-vendor numbers meaningful.

Prices, frugality, and what we refused to spend

Cheap-model trials are shadow-priced from exact token counts; sonnet and frontier trials carry real billed cost per call. Total frontier spend for this entire result: $4.31, and our own audit ruled even that avoidable — the standing rule is that no frontier token is spent re-confirming work the floor already cleared. The frontier matrix (opus, fable, higher efforts) is deliberately unmeasured until a task cracks: absence of data is a decision, not an oversight.

Scope — what these five tasks do and don’t claim

Five hidden-graded tasks, K=3 (K=5 where unstable), one cheap model at the floor, three model families total, single-digit dollars. This is the first sealed layer of a growing record, not a leaderboard. Claims are scoped in HYPOTHESES.md, where each founding hypothesis is scored against the rows that test it — including the one our data challenged.
