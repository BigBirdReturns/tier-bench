How much of the frontier is brute force, and how much is je ne sais quoi?

We measured it. Across seven tasks, real model instances, graded blind: on every task with an operational answer, a cheap model wrapped in a small harness matched or beat the frontier — often for a fraction of the cost. What's left frontier-only turned out to be sand: surface variance that carries no knowledge. Here is the data, and the tool.

The claim, in one line

The frontier's operational edge is mostly an allocation advantage — it looks in more places per pass, and it can search when it can't derive. Both externalize into a harness a cheap model runs. So the moat is real, but it's rentable: capture the frontier's move once, run it cheap and local forever.

Method: every model below is a real instance (claude-haiku-4-5, claude-sonnet-5, claude-opus-4-8). Graders are deterministic; scores regenerate from committed data. Full ledger + reproducibility manifest: experiments/tier-uplift.

Cheap + harness reaches the frontier

Task 04 — subtle bug-finding in a payments ledger, 8 planted bugs, several cross-function. Solo, the tiers separate cleanly. A four-lens sweep (decompose the review, union the findings) lifts each cheap tier to the one above.

haiku 4.0 → 7.5 (clears sonnet, nears opus); sonnet 6.5 → 8.0 (= opus). One harness, two rungs, one task. The bug that separated sonnet from opus — a self-transfer edge case — was caught by the harness's interaction lens more precisely than opus found it solo.

And on an unseen task, with lenses written blind, it beats the frontier

Task 05 uses a frozen, generic lens set — written before the bugs existed, not tuned to them. The fair test of "is it the harness, or the experimenter?" It's the harness.

Left: the cheap model + a checklist it did not write beats the raw frontier model — both missed the same validation bug, but the harness caught it. Right: on a problem haiku genuinely could not derive, letting it write a checker and search found the answer for a fifth of the frontier's price. Its failed solo attempt actually cost more than its winning harness run.

The last moat was sand

Taste looked irreducible — cheap and frontier models rank creative writing differently. But that measured the arrangement, not the knowledge. Split the judgments by whether they actually carry operational content:

On operationally-decisive calls (a clearly-good line vs a clearly-bad one) the cheap model is right 100% of the time — cleaner than the frontier. All the disagreement lives in the near-ties, where the frontier disagrees with itself. That's not a capability. It's sand — surface variance among operationally-equivalent outputs. You don't rent sand; you stop measuring it.

Why this should worry the toll-collectors

Two moats, both flipped by the same move — compile once with the master, run forever cheap and portable.

The inference toll. The industry bills intelligence per token, forever, on someone else's accelerators. But the frontier's operational edge is a reusable checklist, not a per-query miracle. Capture it once; every query after is cheap, local, and yours. Rented capability → owned capability.
The data lock-in. The other moat keeps your knowledge inside a platform that answers by generating over it. AXM Genesis compiles knowledge into a signed, byte-provenanced artifact you hold and query deterministically — no model on the authority path. Inference is a choice, not a primitive.

Honest edge — we did not delete the frontier. It still mints the lenses, the corpus, the oracle, once. The moat didn't vanish; it moved up one level — from doing the work to minting the frame — and everything downstream of the frame is now cheap and portable. That's the inversion: you pay the master once per capability, not once per query.
