1 · Your key

Kept in this browser's localStorage and sent only to api.anthropic.com. It never touches any server of ours — this is a static page. Use a key you're comfortable spending; you can revoke it in the Anthropic console afterward.

Honest about the risk: a key pasted into any web page lives in that page's browser storage and is visible to scripts on this origin. That's the same exposure as putting it in an env var on a shared box — fine for your own machine and your own test, not for a key with broad production scope. This page's only script is the one you're reading.

2 · Your prompts

One prompt per line. Use real, substantial work — code, refactors, analysis. The economy shows up on big outputs; on one-liners the review overhead can cost more than just answering (the page will tell you the truth either way).

3 · The verdict

Reading the numbers. The composite always makes the driver review the cheap draft. When it replies PASS, the frontier generated almost nothing — big savings. When it rewrites, the frontier generated the whole answer and you paid for the draft — no savings. The review runs at low effort by design (glancing at a draft doesn't need deep reasoning). Costs use list pricing per million tokens: fable $10/$50 · opus $5/$25 · sonnet $3/$15 · haiku $1/$5.
